# Oracle APEX Learning

Oracle APEX development project for learning:

- Oracle APEX
- SQL
- PL/SQL
- JavaScript
- Git
- GitHub
- VS Code
- Codex

## Project Structure

- `apex/` - Oracle APEX application exports
- `database/` - Oracle database objects
- `javascript/` - APEX JavaScript
- `css/` - Custom APEX CSS
- `scripts/` - Deployment and installation scripts
- `docs/` - Project documentation
